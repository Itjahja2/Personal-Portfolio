Pantry Pal

Pantry Pal is a full-stack web application that enables users to manage pantry inventory and recipe collections while intelligently identifying which recipes can be prepared with available ingredients. I developed the application using Next.js, React, TypeScript, and PostgreSQL, leveraging Claude Code to accelerate development while designing and implementing the application's architecture, business logic, and user experience.
